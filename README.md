# X99Project

## Teammate setup

Install Node.js LTS (which includes npm) from https://nodejs.org, then open a
terminal in this project's folder. Check the installation:

```sh
node --version
npm --version
```

Install the project's dependencies after cloning or pulling this setup:

```sh
npm ci
```

## Run on localhost

```sh
npm run start
```

Open http://localhost:3000 in your browser. This command builds the CSS, starts
the local Vite server, and watches SCSS changes together. Keep the terminal open
while you work. Saving styles updates the CSS in the browser, and saving HTML
reloads the page. Press **Ctrl+C** to stop both processes.

If port 3000 is already in use, stop the other server or change `server.port` in
`vite.config.mjs`, then run the command again. Use a current Node.js LTS release
for the development server.

## Work on styles without a server

```sh
npm run dev
```

Leave that terminal running while you edit **`scss/index.scss`**. Sass compiles
your saved changes automatically. Press **Ctrl+C** to stop the watcher.
`npm run sass` starts the same watcher if you prefer that command.

Open `index.html` in your browser to view the page, and refresh after saving
changes. This Sass-only command does not start a web server or automatically
refresh the browser. Use `npm run start` for the localhost workflow above.

Write page content in `index.html` and styles in `scss/index.scss`. The HTML
already links to `Index.css`, which is generated by Sass. Avoid editing the
generated CSS directly because the next compilation overwrites it.

For more organization, create partials such as `scss/_header.scss` and load them
from the top of `scss/index.scss` with `@use 'header';`. Keep SCSS files in the
`scss` folder so the watcher picks up changes.

## Build once

```sh
npm run build
```

For compressed CSS:

```sh
npm run build:production
```

Run a build before sharing or deploying. Commit the SCSS source, `Index.css`,
`index.html`, `vite.config.mjs`, `package.json`, and `package-lock.json` so teammates get the same
setup and the page has CSS available without running the watcher. `node_modules`
and development source maps are ignored by Git. After pulling dependency changes,
stop the watcher, run `npm ci`, and start it again.

If the terminal cannot find `node` or `npm`, install Node.js and reopen the
terminal. If it cannot find `sass`, run `npm ci` from the project folder and use
the npm commands above; a global Sass installation is unnecessary.

Sass command reference: https://sass-lang.com/documentation/cli/dart-sass/
